  How to get the Windows .exe built automatically (free, no PC needed)
================================================================

المختصر (Summary)
-----------------
هذا المجلد يحتوي على كل ما يلزم لبناء ملف EXE حقيقي للبرنامج
petroppo يعمل على ويندوز، باستخدام GitHub Actions مجاناً.

لا تحتاج إلى كمبيوتر ويندوز ولا إلى تثبيت أي شيء — كل شيء
يتم تلقائياً على سيرفرات GitHub (windows-latest) ثم تحمل النتيجة.

This folder contains everything needed to build a real Windows .exe
for petroppo using GitHub Actions (free). No Windows PC required.


الخطوات بالتفصيل (Step by step)
================================

1) أنشئ حساب GitHub (إذا لم يكن لديك واحد)
   - اذهب إلى: https://github.com/signup
   - حساب مجاني كافٍ تماماً.
   Create a free GitHub account at https://github.com/signup

2) أنشئ مستودع جديد (Create a new repository)
   - بعد تسجيل الدخول اضغط زر "New" أو +  ثم "New repository"
   - اسم المستودع: petroppo  (أو أي اسم تريده)
   - اختر Private أو Public (لا يهم)
   - لا تضع علامة على "Add a README" ولا "Add .gitignore"
   - اضض "Create repository"
   Click "New repository", name it petroppo, then Create.

3) ارفع ملفات المشروع (Upload the files)
   الطريقة الأسهل (بدون أوامر):
   - في صفحة المستودع الفارغ اضغط "uploading an existing file"
   - اسحب كل محتويات مجلد petroppo_github_build (وليس المجلد نفسه)
     إلى المتصفح — بما في ذلك المجلد المخفي .github
   - تأكد أن مجلد .github موجود بداخله workflows/build_exe.yml
   - اكتب رسالة commit ثم اضغط "Commit changes"

   الطريقة بالأوامر (أسرع):
   If you have git installed, open a terminal in this folder and run:

       git init
       git add -A
       git commit -m "petroppo initial upload"
       git branch -M main
       git remote add origin https://github.com/YOUR_USERNAME/petroppo.git
       git push -u origin main

   Replace YOUR_USERNAME with your GitHub username.

4) شغّل البناء (Trigger the build)
   - بمجرد الرفع على فرع main سيبدأ البناء تلقائياً.
   - أو يدوياً: اذهب إلى تبويب "Actions" في المستودع
     → اختر "Build petroppo Windows EXE"
     → اضغط "Run workflow" → "Run workflow".
   The build triggers automatically on push to main, or manually
   via Actions tab → Run workflow.

5) انتظر البناء (Wait for the build)
   - يستغرق عادة من 6 إلى 12 دقيقة.
   - شاهد التقدم في تبويب Actions (دائرة صفراء = جاري،
     علامة خضراء = نجح، علامة حمراء = فشل).
   Takes about 6-12 minutes. Green check = success.

6) حمّل ملف الـ EXE (Download the exe)
   - بعد نجاح البناء، اضغط على اسم الـ run الناجح.
   - في أسفل الصفحة ستجد قسم "Artifacts":
       * petroppo-portable-exe   →  نسخة محمولة (مجلد كامل فيه petroppo.exe)
       * petroppo-setup-installer →  ملف تثبيت petroppo_setup.exe (يفضّل هذا)
   - اضغط على اسم الـ artifact لتحميل ملف zip.
   Download the artifact "petroppo-setup-installer" (recommended)
   or "petroppo-portable-exe" from the Artifacts section.

7) شغّل البرنامج على ويندوز (Run on Windows)
   - فك ضغط الملف الذي حملته.
   - للنسخة المحمولة: شغّل petroppo.exe مباشرة.
   - للمثبّت: شغّل petroppo_setup.exe → التالي → التالي → تثبيت
     ثم ستجد petroppo في قائمة ابدأ أو اختصار على سطح المكتب.
   Extract and run petroppo.exe (portable) or petroppo_setup.exe (installer).
